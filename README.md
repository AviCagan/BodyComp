# Show up

A workout logger with a 3D **Muscle Map**: every muscle region is colored by how well your logged training
covers it, computed from evidence-based weekly-volume rules, plus a weekly report that says what to add, move,
or cut. iOS + Android from one Expo codebase. Offline-first.

- Plan: `docs/PLAN.md` · Status: `docs/STATUS.md` · Decisions: `docs/DECISIONS.md` · Brief: `docs/brief.pdf`
- Working agreement for Claude Code: `CLAUDE.md`

## Develop

```bash
nvm use            # Node 22
npm ci
npm run check      # typecheck · lint · format · tests · 3D asset validation
npm start          # Metro (use a dev client: `npx expo start --dev-client`)
```

Android dev build: `eas build --profile development --platform android` (free EAS plan) or
`npx expo run:android` with Android Studio + JDK 17. See `docs/STATUS.md`.

## Data

- Exercise catalogue: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Unlicense), imported by
  `npm run seed:import -- <path-to-checkout>`. `src/data/*.json` are generated.
- 3D bodies: Phase 0 placeholder primitives generated by `npm run models:placeholder`; validated by
  `npm run models:validate`. Real anatomy (Z-Anatomy / BodyParts3D, CC BY-SA 4.0) arrives in Phase 1.
